# 🧠 Apprentice Project Builder

A Streamlit app that reads your CV, extracts your skills, compares them against a
curated dataset of UK apprenticeship listings, finds your biggest skill gaps, and
generates tailored project briefs to help you close them.

## 🚀 Features

- **Skill extraction from your CV (PDF)** — fuzzy/synonym-aware matching against a
  142-entry skill list, so "Power-BI", "PowerBI", "Cybersecurity" and similar
  variants are all recognised, while avoiding false positives (e.g. "Java" is not
  matched inside "JavaScript").
- **Skill-gap detection against a curated apprenticeship listings dataset** — 37
  listings spanning three tracks: Data & AI, Network & Infrastructure, and Digital
  Support & Dev. Pick a track in the sidebar to compare against just that track, or
  all of them combined.
- **Demand-ranked gaps** — the three projects generated aren't an arbitrary or
  alphabetical slice of your gaps; they target the skills that appear most
  frequently across the listings in the selected track.
- **AI-generated project briefs** — when an `ANTHROPIC_API_KEY` is configured, each
  brief is generated by Claude using your actual CV skills, the specific skill gap,
  and the job titles/co-required skills that make it relevant, so the suggestions
  are genuinely tailored rather than templated.
- **Template-mode fallback** — with no API key configured (or if the API call
  fails), the app falls back to an offline generator. Tools, objectives and
  difficulty are still tailored per skill (a "Docker" gap gets Docker-relevant
  tools, not generic Python ones) and difficulty is computed from how much of a
  relevant job's other required skills you already have — not hardcoded.
- **The UI always tells you which mode produced a project brief** — AI-generated
  vs template mode — never one silently presented as the other.
- **A bar chart** of skill-gap frequency across the selected track's listings.
- **Download your generated project briefs** as a Markdown file.

## 🧩 Tech Stack

- **Python** / **Streamlit**
- **pypdf** for PDF text extraction
- **rapidfuzz** for fuzzy skill matching
- **anthropic** (Claude API) for AI-generated project briefs, with an offline
  template fallback when no API key is configured
- **matplotlib** for the skill-gap frequency chart
- **pytest** + **ruff** for tests and linting (see `tests/`, run in CI)

## 🧠 How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/M77Rahman/apprentice-project-builder.git
   cd apprentice-project-builder
   ```
2. Create a virtual environment and install dependencies:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
3. (Optional) Enable AI-generated project briefs by setting an Anthropic API key,
   either as an environment variable:
   ```bash
   export ANTHROPIC_API_KEY=sk-ant-...
   ```
   or in `.streamlit/secrets.toml`:
   ```toml
   ANTHROPIC_API_KEY = "sk-ant-..."
   ```
   Without a key, the app runs entirely in template mode — no external API calls
   are made, and the UI says so.
4. Run the app:
   ```bash
   streamlit run app.py
   ```

## ✅ Running Tests

```bash
pip install -r requirements.txt
pytest tests/ -v
ruff check .
```

Both run automatically in CI (`.github/workflows/ci.yml`) on every push and pull
request against `main`.

## 📊 About the Data

`data/jobs_clean.json` is a **curated, static dataset** of 37 realistic UK
apprenticeship listings across three tracks (Data & AI, Network & Infrastructure,
Digital Support & Dev) — it is not pulled live from a job board. To refresh or
extend it, edit the JSON directly; each entry needs a `title`, a `track`
(`data_ai`, `network_infra`, or `digital_support`), and a `skills` list drawn from
`data/skills_list.json`.

`data/skills_list.json` holds the 142 canonical skill names the app recognises,
covering all three tracks (e.g. pandas/scikit-learn/TensorFlow for data & AI;
DNS/DHCP/VPN/Cisco for network & infra; Docker/Kubernetes/REST/GraphQL for
general dev). `src/cv_parser.py` also maintains a synonym map for common
abbreviations and alternate spellings of these skills.
